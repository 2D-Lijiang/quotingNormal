# 纸箱报价系统

一个功能完整的纸箱报价计算系统，采用移动端优先设计，支持模板管理、报价计算、历史记录追踪和数据备份。

## 🎯 功能特性

### 1️⃣ 报价计算模块
- 📋 箱型模板选择（预置3种标准模板）
- 👤 客户信息管理（客户名称、等级、订单数量）
- 📐 纸箱尺寸输入（支持内径/外径切换）
- 📊 楞型选择（A/B/C/E/AB/BC楞）网格化设计
- 🧻 用纸配置（面纸/芯纸/里纸克重）
- 💰 价格参数设置（纸板单价、损耗率）
- 🎨 工艺配置（印刷色数、特殊工艺）
- 💵 自动计算成本拆解（纸料/损耗/工艺/利润/税费）
- 📄 报价单导出功能

### 2️⃣ 箱子模板模块
- 📋 预置标准模板（标准外箱/飞机盒/天地盖）
- ✏️ 自定义模板创建和编辑
- ⚙️ 可配置纸长/纸宽余量
- 🏷️ 模板类型分类（标准/半定制/全自定义）
- ✅ 模板启用/禁用管理
- 🗑️ 模板删除功能

### 3️⃣ 历史记录模块
- 📜 完整报价历史保存
- 🔍 客户名称搜索
- 🏷️ 客户等级筛选
- 📈 统计数据展示（报价次数/总金额/平均单价）
- 📱 报价详情查看（弹窗展示）
- 🔄 历史报价复制功能
- 🗑️ 删除记录管理

### 4️⃣ 系统设置模块
- 📤 数据导出（JSON格式备份）
- 📥 数据导入（从JSON文件恢复）
- 🗑️ 清空历史记录
- 🔄 重置为默认模板
- 💥 清除所有数据

## 📐 计算公式

### 面积计算
```
面积 = ((长 + 宽 + 纸长余量) × (宽 + 高×2 + 纸宽余量) × 2) / 10000
单位：平方米
```

### 成本构成
- **纸料成本** = 面积 × 纸板单价
- **损耗成本** = 纸料成本 × 损耗率
- **工艺成本** = 面积 × (印刷成本 + 特殊工艺成本)
- **利润** = (纸料成本 + 损耗成本 + 工艺成本) × 利润率
- **税费** = (成本小计 + 利润) × 13%

### 客户等级利润率
| 等级 | 利润率 | 说明 |
|------|--------|------|
| 普通客户 | 15% | 标准利润率 |
| 长期客户 | 10% | 优惠利润率 |
| 大客户 | 8% | VIP利润率 |

### 楞型伸长系数

| B楞 | 1.36 |
| C楞 | 1.50 |

## 🚀 快速开始

### 使用方式

1. **直接使用** - 在浏览器中打开 `index.html` 文件

2. **本地服务器** - 推荐使用本地服务器以获得最佳体验：
   ```bash
   # Python 3
   python3 -m http.server 5173
   
   # Node.js (需要 http-server)
   npx http-server
   ```

3. 访问 http://localhost:5173

## 🎮 使用指南

### 创建报价
1. 点击底部 **📦 报价** 标签
2. 选择箱型模板（可选）
3. 填写客户信息和纸箱参数
4. 点击 **🔢 计算报价**
5. 查看成本明细和最终报价
6. 点击 **💾 保存报价** 保存到历史记录

### 管理模板
1. 点击底部 **📋 模板** 标签
2. 点击 **+ 新建** 创建新模板
3. 填写模板名称、类型和配置参数
4. 点击 **保存** 完成创建
5. 点击 **编辑** 或 **删除** 管理现有模板

### 查看历史
1. 点击底部 **📜 历史** 标签
2. 使用搜索框搜索客户名称
3. 使用下拉框筛选客户等级
4. 点击记录查看详情
5. 点击 **复制报价** 快速创建新报价

### 数据备份
1. 点击底部 **⚙️ 我的** 标签
2. 点击 **📤 导出** 备份所有数据
3. 点击 **📥 导入** 从JSON文件恢复数据

## 💡 数据说明

### 存储位置
所有数据保存在浏览器的 **localStorage** 中：
- `carton_templates` - 箱型模板数据
- `carton_history` - 报价历史记录

### 数据格式
导出的JSON文件包含：
```json
{
  "version": "1.0.0",
  "exportTime": "2024-xx-xxTxx:xx:xx",
  "templates": [...],
  "history": [...]
}
```

### 注意事项
- 清除浏览器数据会删除所有保存的信息
- 导入数据会覆盖现有数据
- 重要数据请定期导出备份
