# 纸箱报价系统

一个功能完整的纸箱报价计算系统，支持模板管理、报价计算和历史记录追踪。

## 功能特性

### 1. 报价计算模块
- 📦 支持内径/外径尺寸输入
- 📏 多种楞型选择（A/B/C/E/AB/BC楞）
- 🎨 印刷色数和特殊工艺配置
- 💰 自动计算成本拆解（纸料/损耗/工艺/利润/税费）
- 👥 客户等级利润率设置（普通/长期/VIP）
- 📄 报价单导出功能

### 2. 箱子模板模块
- 📋 预置标准模板（标准外箱/飞机盒/天地盖）
- ✏️ 自定义模板创建和编辑
- ⚙️ 可配置纸长/纸宽余量
- 📊 模板类型分类（标准/半定制/全自定义）

### 3. 历史记录模块
- 📜 完整报价历史保存
- 🔍 客户名称搜索
- 🏷️ 客户等级筛选
- 📈 统计数据展示（报价次数/总金额/平均单价）
- 🔄 历史报价复制功能
- 🗑️ 删除记录管理

## 技术特点

- 🎯 纯前端实现，无需后端服务器
- 💾 数据自动保存到浏览器本地存储
- 📱 响应式设计，支持移动端
- 🎨 现代化UI设计，流畅动画效果
- ⚡ 快速计算，实时显示结果

## 计算公式

### 面积计算
```
面积 = ((长 + 宽 + 纸长余量) × (宽 + 高×2 + 纸宽余量) × 2) / 10000
单位：平方米
```

### 成本构成
- 纸料成本 = 面积 × 纸板单价
- 损耗成本 = 纸料成本 × 损耗率
- 工艺成本 = 面积 × (印刷成本 + 特殊工艺成本)
- 利润 = (纸料成本 + 损耗成本 + 工艺成本) × 利润率
- 税费 = (成本小计 + 利润) × 13%

### 客户等级利润率
- 普通客户：15%
- 长期客户：10%
- VIP客户：8%

### 楞型伸长系数
- A楞：1.53
- B楞：1.36
- C楞：1.50
- E楞：1.27
- AB楞：2.08
- BC楞：2.04

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器预览：
   ```bash
   # 使用Python
   python3 -m http.server 8000
   
   # 使用Node.js (需要http-server)
   npx http-server
   ```
3. 访问 http://localhost:8000

## 数据存储

所有数据保存在浏览器的 localStorage 中，包括：
- 箱型模板
- 报价历史记录

注意：清除浏览器数据会删除所有保存的信息。
